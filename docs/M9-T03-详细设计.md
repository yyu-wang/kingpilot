## 1. 任务回顾

### 1.1 目标

给现有 HTTP API 配一个可直接打开的最小控制台，让非 CLI 用户完成：

- API Key 登录
- 多轮对话（优先走 SSE，实时看到阶段）
- 会话列表切换
- 查看某次请求的 Trace（人类可读，不暴露原始报文）

### 1.2 本卡做

| 能力 | 说明 |
|------|------|
| 静态控制台 | `api/static/` 原生 HTML/CSS/JS，FastAPI 托管 `/console/` |
| 登录 | API Key 存 `sessionStorage`，只放当前标签页 |
| 对话 | 走 `POST /v1/chat/stream`，用 `fetch` 读 SSE（EventSource 不能带自定义头） |
| 会话 | 列表 + 切换 + 历史消息 |
| Trace | 当前会话的 Trace 列表 + 单条报告查看 |
| 安全 | CSP、同源、`textContent` 渲染、后端脱敏与归属校验 |
| 后端补充 | 会话历史、Trace 列表、Trace 详情三个只读接口 |

### 1.3 本卡明确不做

- **不做前端构建链**：不引入 npm / React / Vite / Tailwind
- **不做外部 CDN/字体/图标库**：所有资源本地化
- **不做 Markdown 渲染**：纯文本展示，避免 XSS 面扩大
- **不做用户体系/登录页**：仍用 API Key；正式账号体系不在 M9 范围
- **不做 Trace 原始 JSON 展示**：只返回脱敏后的报告文本
- **不做审批中心/看板**：分别属 M9-T04/T05、T06

### 1.4 验收标准（来自任务卡）

- [ ] 浏览器可完成多轮对话并查看对应 Trace
- [ ] 会话切换正确
- [ ] 移动端基本可用
- [ ] 无外部 CDN 依赖

## 3. 关键设计决策（需审批）

### D1. 控制台由 FastAPI 同源托管

```
GET /            → 302/307 → /console/
GET /console/    → api/static/index.html
GET /console/app.js / styles.css
```

- 用 Starlette `StaticFiles(directory, html=True)`，不新增依赖
- 同源带来三个好处：无 CORS、API Key 不跨域、CSP 可收紧到 `'self'`
- 生产仍建议放在网关之后（TLS/限流）

### D2. API Key 只进 `sessionStorage`

- 登录成功后写 `sessionStorage`（关闭标签页即清除）
- 不使用 `localStorage`（长期驻留风险更大）
- 不使用 Cookie（避免 CSRF；API 现有认证就是请求头）
- 登出 = 清除 `sessionStorage` + 回到登录层
- 页面不把 key 写进 URL、日志或 DOM 文本

### D3. SSE 用 `fetch` 而不是 `EventSource`

`EventSource` 不支持自定义请求头，无法带 `X-API-Key`，因此：

```js
fetch('/v1/chat/stream', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json', 'X-API-Key': key },
  body: JSON.stringify({ message, session_id })
})
```

然后手写一个极小的 SSE 帧解析器（`event:` / `data:` / 空行分隔 / `:` 心跳）。

### D4. 历史消息只返回 user/assistant，且统一脱敏

新增 `GET /v1/sessions/{session_id}/messages`：

- 只返回 `role in {user, assistant}`，**不返回 tool 原始结果**
- 每条 `content` 先过 `redact_text`（手机号/身份证/银行卡/邮箱掩码）
- 再逐条过 `DlpScanner` 兜底；仍命中则替换为安全占位文案
- 文件不存在 / 不属于当前用户 → 404

**边界**：历史来自 Layer 1；记忆压缩后早期轮次会被摘要替代，界面只展示当前保留的近期原文。完整决策链看 Trace。

### D5. Trace 只返回脱敏报告，不返回原始 JSON

新增：

- `GET /v1/traces?session_id=...`：当前用户的 Trace 摘要列表
- `GET /v1/traces/{trace_id}`：单条报告

安全规则：

1. `trace.user_id != 当前用户` → 404（不暴露“存在但不属于你”）
2. 报告 = `render_trace_report(trace)` → `redact_text` → `DlpScanner` 兜底
3. 返回 `report_text` + 少量元信息；**不返回 `tool_executions` 原始 `result`**
4. 非法/不存在 trace_id → 404

### D6. 扩展 `TraceInfo` 支持服务端过滤

`TraceInfo` 增加两个带默认值的字段：

```python
user_id: str = ""
session_id: str = ""
```

`list_traces()` 加载时填充。这样 API 可以在服务端按用户/会话过滤，控制台不需要拉全量再筛。

### D7. 前端只做安全的文本渲染

- 所有动态内容用 `textContent`，禁止把模型/用户内容拼进 `innerHTML`
- 不使用 `eval` / `new Function` / 内联事件处理器
- CSP：

```
default-src 'self';
script-src 'self';
style-src 'self';
img-src 'self' data:;
connect-src 'self';
base-uri 'none';
frame-ancestors 'none'
```

- 额外响应头：`X-Content-Type-Options: nosniff`、`Referrer-Policy: no-referrer`、`X-Frame-Options: DENY`

### D8. 不引入前端构建链与外部资源

- 静态文件：`index.html` / `app.js` / `styles.css` / `favicon.svg`
- 系统字体栈，无 Google Fonts
- 无图标库，按钮用文字/Unicode 符号（如 `＋`、`↻`）
- 无 CDN：静态测试会扫描 `http://` / `https://` 外链

### D9. 控制台采用「三栏 + 移动端堆叠」

```
┌──────────────────────────────────────────────────────────┐
│ Header：KingPilot / 当前用户 / 登出                        │
├──────────────┬──────────────────────────┬────────────────┤
│ 会话列表      │ 对话区（流式状态 + 消息）  │ Trace 列表/报告  │
│ + 新建会话    │                          │                │
└──────────────┴──────────────────────────┴────────────────┘
```

- 桌面：`grid-template-columns: 240px 1fr 360px`
- ≤ 900px：Trace 面板折叠到对话下方
- ≤ 640px：会话列表改为顶部横向滚动
- 输入框 Enter 发送、Shift+Enter 换行；流式期间禁用发送

### D10. Trace 与消息的关联方式

- 实时对话：`final` 事件带 `trace_id`，前端把它挂到该条 assistant 消息上，消息旁显示「查看 Trace」
- 历史对话：Session 文件不存 trace_id，因此右侧按 `session_id` 列出该会话全部 Trace，点击查看
- 不修改 Session 存储 schema（避免为一个 UI 需求做数据迁移）

## 4. API 契约新增

### 4.1 `GET /v1/sessions/{session_id}/messages`

响应 200：

```json
{
  "session_id": "a1b2c3d4e5f6",
  "messages": [
    {"role": "user", "content": "查询销售订单 SO000001"},
    {"role": "assistant", "content": "查到 1 条销售订单……"}
  ]
}
```

错误：

| HTTP | code | 场景 |
|------|------|------|
| 400 | `session_invalid` | session_id 非法 |
| 404 | `session_not_found` | 文件不存在 / 不属于当前用户 |

### 4.2 `GET /v1/traces?session_id=...&limit=50`

响应 200：

```json
{
  "traces": [
    {
      "trace_id": "…",
      "session_id": "a1b2c3d4e5f6",
      "user_input": "查询销售订单 SO000001",
      "used_fallback": false,
      "total_latency_ms": 812.5,
      "saved_at": "2026-10-19T10:00:00+00:00"
    }
  ]
}
```

- `session_id` 可选；不传 = 当前用户全部 Trace
- `limit` 默认 50，范围 1~200
- 只返回当前用户的 Trace；`user_input` 脱敏并截断到 120 字符，避免列表被长输入撑爆

### 4.3 `GET /v1/traces/{trace_id}`

响应 200：

```json
{
  "trace_id": "…",
  "session_id": "a1b2c3d4e5f6",

  "final_response": "查到 1 条销售订单……",
  "report_text": "Trace View (trace_id: …)\n├── 用户: alice ..."
```

错误：非法/不存在/非本人 → 404 `trace_not_found`。

### Step 3：会话历史接口

`api/traces.py`：

```python
@router.get("/v1/sessions/{session_id}/messages", response_model=SessionMessagesResponse)
async def session_messages(
    session_id: str,
    request: Request,
    user: Annotated[UserContext, Depends(get_current_user)],
) -> SessionMessagesResponse:
    store = get_deps(request).store_for(user.user_id)
    try:
        path = store.path_for(session_id)
    except SessionStoreError as exc:
        raise ApiError(400, "session_invalid", "会话 ID 非法") from exc
    if not path.exists():
        raise ApiError(404, "session_not_found", "会话不存在")

    try:
        memory = store.load(session_id)
    except SessionStoreError as exc:
        raise ApiError(400, "session_invalid", "会话不存在或已损坏") from exc

    messages: list[MessageView] = []
    for raw in memory.raw_messages():
        if raw.role not in ("user", "assistant"):
            continue  # 工具原始结果不进历史接口
        content = redact_text(raw.content)
        if DlpScanner().scan(content).blocked:
            content = "（该条内容包含敏感信息，已阻断展示）"
        messages.append(MessageView(role=raw.role, content=content))
    return SessionMessagesResponse(session_id=session_id, messages=messages)
```

### Step 4：Trace 列表与详情

```python
@router.get("/v1/traces", response_model=TraceListResponse)
async def list_traces(
    request: Request,
    user: Annotated[UserContext, Depends(get_current_user)],
    session_id: str = "",
    limit: int = 50,
) -> TraceListResponse:
    deps = get_deps(request)
    limit = max(1, min(limit, 200))
    infos = [
        info
        for info in deps.trace_store.list_traces()
        if info.user_id == user.user_id and (not session_id or info.session_id == session_id)
    ][:limit]
    return TraceListResponse(
        traces=[
            TraceSummary(
                trace_id=info.trace_id,
                session_id=info.session_id,
                user_input=info.user_input,
                used_fallback=info.used_fallback,
                total_latency_ms=info.total_latency_ms,
                saved_at=info.saved_at,
            )
            for info in infos
        ]
    )


@router.get("/v1/traces/{trace_id}", response_model=TraceView)
async def get_trace(
    trace_id: str,
    request: Request,
    user: Annotated[UserContext, Depends(get_current_user)],
) -> TraceView:
    deps = get_deps(request)
    try:
        trace = deps.trace_store.load(trace_id)
    except TraceStoreError as exc:
        raise ApiError(404, "trace_not_found", "Trace 不存在") from exc
    if trace.user_id != user.user_id:
        raise ApiError(404, "trace_not_found", "Trace 不存在")

    report = redact_text(render_trace_report(trace))
    if DlpScanner().scan(report).blocked:
        report = "（Trace 包含敏感信息，已阻断展示）"
    return TraceView(
        trace_id=str(trace.trace_id),
        session_id=trace.session_id,
        user_id=trace.user_id,
        user_input=redact_text(trace.user_input),
        final_response=redact_text(trace.final_response),
        report_text=report,
    )
```

要点：

- 归属不符统一 404，避免枚举
- 只返回报告文本，不返回原始 `tool_executions`
- `redact_text` 先掩码，`DlpScanner` 再兜底

### Step 7：前端核心逻辑

`api/static/app.js` 关键片段：

```js
const KEY_STORAGE = 'kingpilot.apiKey';
let apiKey = sessionStorage.getItem(KEY_STORAGE) || '';
let sessionId = '';
let streaming = false;

async function apiFetch(path, options = {}) {
  const response = await fetch(path, {
    ...options,
    headers: {
      'Content-Type': 'application/json',
      'X-API-Key': apiKey,
      ...(options.headers || {}),
    },
  });
  if (response.status === 401) {
    logout();
    throw new Error('API Key 无效或已过期');
  }
  if (!response.ok) {
    const body = await response.json().catch(() => null);
    throw new Error(body?.error?.message || `请求失败（${response.status}）`);
  }
  return response;
}

async function streamChat(message) {
  const response = await apiFetch('/v1/chat/stream', {
    method: 'POST',
    body: JSON.stringify({ message, session_id: sessionId }),
  });
  const reader = response.body.getReader();
  const decoder = new TextDecoder();
  let buffer = '';

  while (true) {
    const { value, done } = await reader.read();
    if (done) break;
    buffer += decoder.decode(value, { stream: true }).replace(/\r\n/g, '\n');
    let index;
    while ((index = buffer.indexOf('\n\n')) >= 0) {
      const frame = buffer.slice(0, index);
      buffer = buffer.slice(index + 2);
      const event = parseFrame(frame);
      if (event) handleEvent(event);
    }
  }
}

function parseFrame(frame) {
  let eventName = 'message';
  const dataLines = [];
  for (const line of frame.split('\n')) {
    if (line.startsWith(':')) continue;
    if (line.startsWith('event:')) eventName = line.slice(6).trim();
    if (line.startsWith('data:')) dataLines.push(line.slice(5).trim());
  }
  if (!dataLines.length) return null;
  return { type: eventName, payload: JSON.parse(dataLines.join('\n')) };
}

function appendMessage(role, content, traceId = '') {
  const item = document.createElement('article');
  item.className = `message message-${role}`;

  const body = document.createElement('div');
  body.className = 'message-body';
  body.textContent = content;  // 关键：绝不使用 innerHTML

  item.appendChild(body);
  if (traceId) {
    const button = document.createElement('button');
    button.type = 'button';
    button.className = 'link-button';
    button.textContent = '查看 Trace';
    button.addEventListener('click', () => openTrace(traceId));
    item.appendChild(button);
  }
  messagesEl.appendChild(item);
  messagesEl.scrollTop = messagesEl.scrollHeight;
}
```

```js
function handleEvent({ type, payload }) {
  if (type === 'phase') {
    phaseStatusEl.textContent = `${payload.phase} · ${payload.status}`;
  } else if (type === 'tool') {
    phaseStatusEl.textContent =
      `工具 ${payload.tool_name} · ${payload.status}` +
      (payload.latency_ms ? `（${Math.round(payload.latency_ms)}ms）` : '');
  } else if (type === 'final') {
    sessionId = payload.session_id || sessionId;
    appendMessage('assistant', payload.content, payload.trace_id);
    phaseStatusEl.textContent = payload.blocked ? '已按安全策略阻断' : '';
    refreshSessions();
    refreshTraces();
  } else if (type === 'error') {
    phaseStatusEl.textContent = payload.message;
  } else if (type === 'done') {
    streaming = false;
    setComposerDisabled(false);
  }
}
```

```js
  const response = await apiFetch(`/v1/traces${query}`);
  const body = await response.json();
  traceListEl.replaceChildren(

      button.className = 'trace-item';
      button.textContent = `${trace.user_input || '(无输入)'} · ${Math.round(trace.total_latency_ms)}ms`;
      button.addEventListener('click', () => openTrace(trace.trace_id));

    }),
  );
}
```

## 8. 风险与边界

| 风险 | 处理 |
|------|------|
| XSS | 全量 `textContent`；CSP 禁止内联；无第三方脚本 |
| API Key 泄露 | `sessionStorage`；不出现在 URL/DOM；CSP 限制外联 |
| Trace 含敏感数据 | 只返回脱敏报告；归属校验；DLP 兜底 |
| 历史不完整 | Layer 1 压缩后只保留近期原文；文档明确；看 Trace 获取完整链路 |
| 大 Trace 目录扫描慢 | `limit` 默认 50；本地文件量级可接受；后续可做索引 |
| 静态文件未进 wheel | 已验证：wheel 包含 `api/static/index.html`、`app.js`、`styles.css` |
| 流式解析兼容性 | 手写解析器兼容 CRLF、空行、`:` 心跳；失败显示错误 |
| 无 JS 自动化测试 | 后端契约 + 静态扫描 + 手工浏览器验收；后续可引入 Playwright |
