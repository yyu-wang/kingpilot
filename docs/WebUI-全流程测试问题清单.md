```bash
curl -s http://127.0.0.1:8080/v1/badcases -H 'X-API-Key: <KEY>'
```

预期：标记成功、同一 trace 重复标记幂等、列表可查。

```bash
curl -s http://127.0.0.1:8080/v1/approvals -H 'X-API-Key: <KEY>'
```
